# loop

Five small, runnable pieces of a compiler-engineer toolkit: an SSA IR with two
passes, the same DCE written against the real LLVM C++ API, MLIR fusion and
tiling, a C++ memory-ownership set, and a CUDA GEMM with a measured speedup.

Everything here builds and runs. Each directory is one idea, kept small enough
to read in a sitting and rewrite from scratch.

## Layout

| Directory | What it is |
|---|---|
| `toy-ir/` | A tiny SSA IR (`const`, `add`, `mul`, `relu`, `store`, `return`) plus dead-code elimination and constant CSE, in one file |
| `llvm-pass/` | The same DCE on `llvm::Module` / `Instruction`, using `isInstructionTriviallyDead` |
| `mlir-pass/` | `linalg` elementwise fusion and `affine` loop tiling through `mlir-opt` |
| `cpp/` | Eight programs on pointers vs references, `vector` invalidation, `unique_ptr`, and undefined behavior |
| `kernels/` | Naive vs 16×16 shared-memory-tiled GEMM, timed with CUDA events |

## Build and run

```bash
make -C toy-ir study && ./toy-ir/study
make -C llvm-pass run      # needs llvm-config; override with LLVM_CONFIG=...
make -C mlir-pass run      # needs mlir-opt; override with OPT=...
make -C cpp run
make -C kernels run        # needs nvcc + an NVIDIA GPU
```

## Results

**`toy-ir`** — DCE removes a dead `const 99`, and removes two instructions when
a `mul` is unused and its `const` dies with it. CSE collapses duplicate
immediates and rewrites their users.

**`llvm-pass`** — on `input.ll`, `%dead` disappears and the live `add` stays:

```llvm
define i32 @f(i32 %x) {
  %y = add i32 %x, 2
  ret i32 %y
}
```

**`mlir-pass`** — `--linalg-fuse-elementwise-ops` turns two `linalg.generic` ops
into one whose body does `arith.addf` then `arith.mulf`: one loop nest, one
write to the output tensor. `--affine-loop-tile="tile-size=32"` splits the
`affine.for` over 128 into an outer step-32 loop and an inner 32-trip loop.

**`kernels`** — N=1024, RTX A3000 Laptop, mean of 10 launches:

| Kernel | Time |
|---|---|
| naive | 3.59 ms |
| 16×16 tiled | 2.71 ms |

Max elementwise difference against the naive result is 0.

## Notes

**DCE walks backward.** `store` and `return` are live roots and mark their
operands live. Going forward in a single pass reaches a definition before its
uses, so it would delete values that are still needed. Backward, the live set is
already complete by the time each definition is visited, which also handles
transitively dead chains.

**CSE rewrites operands before deleting.** Operands go through the remap table
first; only then is a duplicate `const` dropped. Delete first and later
instructions still name an id that no longer exists.

**The GEMM win is reuse, not arithmetic.** Both kernels do the same N³
multiply-adds. The naive kernel reloads a row of A and a column of B from global
memory on every `k`. The tiled kernel stages a 16×16 block of each into shared
memory and reuses it across the block, so the bottleneck moves off global
memory bandwidth.

**Ownership.** `unique_ptr` owns each child node; `reset()` frees that subtree,
and no destructor calls `delete` by hand.

// One file: a list of instructions, then DCE, then CSE.
// Run:  make -C toy-ir study && ./toy-ir/study
//
// Picture (not a tree): a LIST, top to bottom.
//   v1 = const 99
//   v2 = const 1
//   v3 = add v0, v2
//        return v3
// Names (v0, v1, ...) can be used more than once = a DAG of values.

#include <algorithm>
#include <cassert>
#include <cstdint>
#include <iostream>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>

enum class Opcode : uint8_t
{
  Const,
  Add,
  Mul,
  Relu,
  Load,
  Store,
  Return
};

// One line of IR.
struct Inst
{
  Opcode op{};
  int id = -1;               // name of the result: v1, v2, ...  (-1 = no result)
  std::vector<int> operands; // names this line reads (e.g. add uses v0 and v2)
  double imm = 0.0;          // only for Const: the number 99 or 1
};

// One basic block: just a vector of Inst, in order.
struct Block
{
  std::string name;
  std::vector<Inst> insts;
};

struct Function
{
  std::string name;
  std::vector<int> args; // v0 is usually the argument, not an Inst
  std::vector<Block> blocks;
  int next_id = 0;
  int fresh()
  {
    return next_id++;
  } // 0, then 1, then 2, ...
};

// ---------------------------------------------------------------------------
// DCE = delete lines whose result nobody needs.
//
// Paper (first test in main). Start at the BOTTOM. live = names still needed.
//
//   return v3          keep (return always stays).  live = {v3}
//   v3 = add v0, v2    v3 is live -> keep.          live = {v3, v0, v2}
//   v2 = const 1       v2 is live -> keep.
//   v1 = const 99      v1 is NOT live -> DELETE.
//
// Flip kept lines back to top-to-bottom:  const 1, add, return.
//
// Walk BACKWARD so you see "who needs this" before you decide to delete.
// Walk forward and you meet const 99 first, with live still empty — wrong.
// store/return are roots: they stay even if they have no id.
// ---------------------------------------------------------------------------
int dce(Function &fn)
{
  int removed = 0;
  for (Block &bb : fn.blocks)
  {
    std::unordered_set<int> live; // names the return still needs
    std::vector<Inst> kept;       // we push bottom-up, reverse at the end
    for (int i = static_cast<int>(bb.insts.size()) - 1; i >= 0; --i)
    {
      const Inst &inst = bb.insts[i];
      const bool root = inst.op == Opcode::Store || inst.op == Opcode::Return;
      const bool result_live = inst.id >= 0 && live.count(inst.id);
      if (!root && !result_live)
      {
        ++removed; // nobody needs this result
        continue;
      }
      for (int op : inst.operands)
      {
        live.insert(op); // those names are now needed
      }
      kept.push_back(inst);
    }
    std::reverse(kept.begin(), kept.end());
    bb.insts = std::move(kept);
  }
  return removed;
}

// ---------------------------------------------------------------------------
// CSE (const only) = one "const 2", not two.
//
// Paper (third test in main):
//   v1 = const 2
//   v2 = const 2          same number -> drop v2, remember v2 means v1
//   v3 = add v0, v1
//   v4 = mul v3, v2       rewrite v2 -> v1 BEFORE you would look at mul
//        return v4
//
// remap: old name -> name we kept.  FIRST rewrite operands, THEN drop duplicate.
// Delete v2 first and mul still says v2 -> broken.
// ---------------------------------------------------------------------------
int cse_const(Function &fn)
{
  int replaced = 0;
  for (Block &bb : fn.blocks)
  {
    std::unordered_map<int, int> remap;          // v2 -> v1
    std::unordered_map<double, int> first_const; // 2.0 -> v1
    std::vector<Inst> kept;
    for (Inst inst : bb.insts)
    {
      for (int &op : inst.operands)
      {
        auto it = remap.find(op);
        if (it != remap.end())
        {
          op = it->second; // use the first copy's id
        }
      }
      if (inst.op == Opcode::Const)
      {
        auto it = first_const.find(inst.imm);
        if (it != first_const.end())
        {
          remap[inst.id] = it->second;
          ++replaced;
          continue; // do not keep this duplicate const
        }
        first_const.emplace(inst.imm, inst.id);
      }
      kept.push_back(std::move(inst));
    }
    bb.insts = std::move(kept);
  }
  return replaced;
}

int main()
{
  // --- DCE example 1: drop unused const 99 ---
  // v0=x, v1=99, v2=1, v3=add(v0,v2), return v3
  {
    Function fn;
    int x = fn.fresh();
    fn.args.push_back(x);
    Inst dead{Opcode::Const, fn.fresh(), {}, 99.0};
    Inst c1{Opcode::Const, fn.fresh(), {}, 1.0};
    Inst add{Opcode::Add, fn.fresh(), {x, c1.id}};
    Inst ret{Opcode::Return, -1, {add.id}};
    fn.blocks.push_back({"entry", {dead, c1, add, ret}});
    assert(dce(fn) == 1);                   // only const 99 removed
    assert(fn.blocks[0].insts.size() == 3); // const 1, add, return
    assert(fn.blocks[0].insts[0].imm == 1.0);
  }

  // --- DCE example 2: unused mul, so its const dies too ---
  // v1=const 5, v2=mul(x,v1) unused, v3=relu(x), return v3
  {
    Function fn;
    int x = fn.fresh();
    Inst c{Opcode::Const, fn.fresh(), {}, 5.0};
    Inst mul{Opcode::Mul, fn.fresh(), {x, c.id}};
    Inst relu{Opcode::Relu, fn.fresh(), {x}};
    Inst ret{Opcode::Return, -1, {relu.id}};
    fn.blocks.push_back({"entry", {c, mul, relu, ret}});
    assert(dce(fn) == 2); // mul and const 5
    assert(fn.blocks[0].insts[0].op == Opcode::Relu);
  }

  // --- CSE: two const 2 -> one; mul must use the first id ---
  {
    Function fn;
    int x = fn.fresh();
    Inst c1{Opcode::Const, fn.fresh(), {}, 2.0};
    Inst c2{Opcode::Const, fn.fresh(), {}, 2.0};
    Inst add{Opcode::Add, fn.fresh(), {x, c1.id}};
    Inst mul{Opcode::Mul, fn.fresh(), {add.id, c2.id}};
    Inst ret{Opcode::Return, -1, {mul.id}};
    fn.blocks.push_back({"entry", {c1, c2, add, mul, ret}});
    assert(cse_const(fn) == 1);
    assert(fn.blocks[0].insts[2].operands[1] == fn.blocks[0].insts[0].id);
  }

  std::cout << "STUDY: DCE + CSE ok\n";
  return 0;
}

// Real LLVM: load a module, drop trivially dead insts, print IR.
#include "llvm/IR/Function.h"
#include "llvm/IR/InstIterator.h"
#include "llvm/IR/Instructions.h"
#include "llvm/IR/LLVMContext.h"
#include "llvm/IR/Module.h"
#include "llvm/IRReader/IRReader.h"
#include "llvm/Support/SourceMgr.h"
#include "llvm/Support/raw_ostream.h"
#include "llvm/Transforms/Utils/Local.h"

#include <string>

using namespace llvm;

static int dce_function(Function &fn)
{
  int removed = 0;
  bool changed = true;
  while (changed)
  {
    changed = false;
    for (BasicBlock &bb : fn)
    {
      // Backward: a def is only dropped after later uses are gone.
      for (Instruction *inst = &bb.back(); inst != nullptr;)
      {
        Instruction *prev = inst->getPrevNode();
        if (isInstructionTriviallyDead(inst))
        {
          inst->eraseFromParent();
          ++removed;
          changed = true;
        }
        inst = prev;
      }
    }
  }
  return removed;
}

int main(int argc, char **argv)
{
  if (argc != 2)
  {
    errs() << "usage: dce <file.ll>\n";
    return 1;
  }

  LLVMContext ctx;
  SMDiagnostic err;
  auto mod = parseIRFile(argv[1], err, ctx);
  if (!mod)
  {
    err.print("dce", errs());
    return 1;
  }

  int removed = 0;
  for (Function &fn : *mod)
  {
    if (!fn.isDeclaration())
    {
      removed += dce_function(fn);
    }
  }
  errs() << "removed " << removed << "\n";
  mod->print(outs(), nullptr);
  return 0;
}

// Before: two elementwise generics (add, then mul). Two tensor results.
// After:  mlir-opt --linalg-fuse-elementwise-ops -> one generic: addf then mulf.
#map = affine_map<(d0) -> (d0)>

func.func @add_mul(%a: tensor<8xf32>, %b: tensor<8xf32>, %c: tensor<8xf32>) -> tensor<8xf32> {
  %empty = tensor.empty() : tensor<8xf32>
  %add = linalg.generic {
      indexing_maps = [#map, #map, #map],
      iterator_types = ["parallel"]
    } ins(%a, %b : tensor<8xf32>, tensor<8xf32>)
      outs(%empty : tensor<8xf32>) {
    ^bb0(%x: f32, %y: f32, %out: f32):
      %s = arith.addf %x, %y : f32
      linalg.yield %s : f32
  } -> tensor<8xf32>
  %mul = linalg.generic {
      indexing_maps = [#map, #map, #map],
      iterator_types = ["parallel"]
    } ins(%add, %c : tensor<8xf32>, tensor<8xf32>)
      outs(%empty : tensor<8xf32>) {
    ^bb0(%x: f32, %y: f32, %out: f32):
      %p = arith.mulf %x, %y : f32
      linalg.yield %p : f32
  } -> tensor<8xf32>
  return %mul : tensor<8xf32>
}

int main()
{
  std::vector<int> v = {1, 2, 3, 4, 5};

  // Wrong: save it = v.begin()+2, erase, then use it again → UB.
  // Right: erase returns the next live iterator.
  for (auto it = v.begin(); it != v.end();)
  {
    if (*it == 3)
    {
      it = v.erase(it);
    }
    else
    {
      ++it;
    }
  }

  for (int x : v)
  {
    std::cout << x << " ";
  }
  std::cout << "\n"; // 1 2 4 5
  return 0;
}

// Naive GEMM vs 16x16 shared-memory tile.
// Story: same math, fewer global loads of A/B. Print both times.

#include <cuda_runtime.h>
#include <cmath>
#include <cstdio>
#include <cstdlib>
#include <vector>

static constexpr int TILE = 16;

#define CHECK(call)                                                            \
  do                                                                           \
  {                                                                            \
    cudaError_t err = (call);                                                  \
    if (err != cudaSuccess)                                                    \
    {                                                                          \
      fprintf(stderr, "%s:%d %s\n", __FILE__, __LINE__,                        \
              cudaGetErrorString(err));                                        \
      exit(1);                                                                 \
    }                                                                          \
  } while (0)

__global__ void gemm_naive(const float *A, const float *B, float *C, int N)
{
  int row = blockIdx.y * blockDim.y + threadIdx.y;
  int col = blockIdx.x * blockDim.x + threadIdx.x;
  if (row >= N || col >= N)
  {
    return;
  }
  float acc = 0.f;
  for (int k = 0; k < N; ++k)
  {
    acc += A[row * N + k] * B[k * N + col];
  }
  C[row * N + col] = acc;
}

__global__ void gemm_tiled(const float *A, const float *B, float *C, int N)
{
  __shared__ float As[TILE][TILE];
  __shared__ float Bs[TILE][TILE];
  int row = blockIdx.y * TILE + threadIdx.y;
  int col = blockIdx.x * TILE + threadIdx.x;
  float acc = 0.f;
  for (int t = 0; t < N; t += TILE)
  {
    int a_col = t + threadIdx.x;
    int b_row = t + threadIdx.y;
    As[threadIdx.y][threadIdx.x] =
        (row < N && a_col < N) ? A[row * N + a_col] : 0.f;
    Bs[threadIdx.y][threadIdx.x] =
        (b_row < N && col < N) ? B[b_row * N + col] : 0.f;
    __syncthreads();
    for (int k = 0; k < TILE; ++k)
    {
      acc += As[threadIdx.y][k] * Bs[k][threadIdx.x];
    }
    __syncthreads();
  }
  if (row < N && col < N)
  {
    C[row * N + col] = acc;
  }
}

static float time_ms(void (*launch)(const float *, const float *, float *, int,
                                    int),
                     const float *A, const float *B, float *C, int N, int grid)
{
  launch(A, B, C, N, grid);
  CHECK(cudaDeviceSynchronize());
  cudaEvent_t start, stop;
  CHECK(cudaEventCreate(&start));
  CHECK(cudaEventCreate(&stop));
  CHECK(cudaEventRecord(start));
  for (int i = 0; i < 10; ++i)
  {
    launch(A, B, C, N, grid);
  }
  CHECK(cudaEventRecord(stop));
  CHECK(cudaEventSynchronize(stop));
  float ms = 0.f;
  CHECK(cudaEventElapsedTime(&ms, start, stop));
  CHECK(cudaEventDestroy(start));
  CHECK(cudaEventDestroy(stop));
  return ms / 10.f;
}

static void launch_naive(const float *A, const float *B, float *C, int N, int)
{
  dim3 block(TILE, TILE);
  dim3 grid((N + TILE - 1) / TILE, (N + TILE - 1) / TILE);
  gemm_naive<<<grid, block>>>(A, B, C, N);
}

static void launch_tiled(const float *A, const float *B, float *C, int N, int)
{
  dim3 block(TILE, TILE);
  dim3 grid((N + TILE - 1) / TILE, (N + TILE - 1) / TILE);
  gemm_tiled<<<grid, block>>>(A, B, C, N);
}

int main()
{
  const int N = 1024;
  std::vector<float> hA(N * N), hB(N * N), hC(N * N), hRef(N * N);
  for (int i = 0; i < N * N; ++i)
  {
    hA[i] = 0.001f * (i % 17);
    hB[i] = 0.001f * (i % 13);
  }
  float *A, *B, *C;
  CHECK(cudaMalloc(&A, hA.size() * sizeof(float)));
  CHECK(cudaMalloc(&B, hB.size() * sizeof(float)));
  CHECK(cudaMalloc(&C, hC.size() * sizeof(float)));
  CHECK(cudaMemcpy(A, hA.data(), hA.size() * sizeof(float),
                    cudaMemcpyHostToDevice));
  CHECK(cudaMemcpy(B, hB.data(), hB.size() * sizeof(float),
                    cudaMemcpyHostToDevice));

  launch_naive(A, B, C, N, 0);
  CHECK(cudaDeviceSynchronize());
  CHECK(cudaMemcpy(hRef.data(), C, hRef.size() * sizeof(float),
                    cudaMemcpyDeviceToHost));
  launch_tiled(A, B, C, N, 0);
  CHECK(cudaDeviceSynchronize());
  CHECK(cudaMemcpy(hC.data(), C, hC.size() * sizeof(float),
                    cudaMemcpyDeviceToHost));
  double max_abs = 0;
  for (int i = 0; i < N * N; ++i)
  {
    max_abs = std::max(max_abs, (double)std::fabs(hC[i] - hRef[i]));
  }

  float naive = time_ms(launch_naive, A, B, C, N, 0);
  float tiled = time_ms(launch_tiled, A, B, C, N, 0);
  printf("N=%d tile=%d\n", N, TILE);
  printf("naive  %.3f ms\n", naive);
  printf("tiled  %.3f ms\n", tiled);
  printf("max |tiled-naive| %.3g\n", max_abs);
  printf("why: each A/B element is reused from shared memory inside the tile "
         "instead of reloaded from global memory on every k\n");

  CHECK(cudaFree(A));
  CHECK(cudaFree(B));
  CHECK(cudaFree(C));
  return max_abs > 1e-3 ? 1 : 0;
}

## Results

**`toy-ir`** — DCE removes a dead `const 99`, and removes two instructions when
a `mul` is unused and its `const` dies with it. CSE collapses duplicate
immediates and rewrites their users.

**`llvm-pass`** — on `input.ll`, `%dead` disappears and the live `add` stays:

```llvm
define i32 @f(i32 %x) {
  %y = add i32 %x, 2
  ret i32 %y
}
```

**`mlir-pass`** — `--linalg-fuse-elementwise-ops` turns two `linalg.generic` ops
into one whose body does `arith.addf` then `arith.mulf`: one loop nest, one
write to the output tensor. `--affine-loop-tile=&quot;tile-size=32&quot;` splits the
`affine.for` over 128 into an outer step-32 loop and an inner 32-trip loop.

**`kernels`** — N=1024, RTX A3000 Laptop, mean of 10 launches:

| Kernel | Time |
|---|---|
| naive | 3.59 ms |
| 16×16 tiled | 2.71 ms |

## Notes

**DCE walks backward.** `store` and `return` are live roots and mark their
operands live. Going forward in a single pass reaches a definition before its
uses, so it would delete values that are still needed. Backward, the live set is
already complete by the time each definition is visited, which also handles
transitively dead chains.

**CSE rewrites operands before deleting.** Operands go through the remap table
first; only then is a duplicate `const` dropped. Delete first and later
instructions still name an id that no longer exists.

**The GEMM win is reuse, not arithmetic.** Both kernels do the same N³
multiply-adds. The naive kernel reloads a row of A and a column of B from global
memory on every `k`. The tiled kernel stages a 16×16 block of each into shared
memory and reuses it across the block, so the bottleneck moves off global
memory bandwidth.

**Ownership.** `unique_ptr` owns each child node; `reset()` frees that subtree,
and no destructor calls `delete` by hand.

<h2 id='toy-ir-STUDY-cpp'>toy-ir/STUDY.cpp</h2>
<pre>// One file: a list of instructions, then DCE, then CSE.
// Run:  make -C toy-ir study &amp;&amp; ./toy-ir/study
//
// Picture (not a tree): a LIST, top to bottom.
//   v1 = const 99
//   v2 = const 1
//   v3 = add v0, v2
//        return v3
// Names (v0, v1, ...) can be used more than once = a DAG of values.

#include &lt;algorithm&gt;
#include &lt;cassert&gt;
#include &lt;cstdint&gt;
#include &lt;iostream&gt;
#include &lt;string&gt;
#include &lt;unordered_map&gt;
#include &lt;unordered_set&gt;
#include &lt;vector&gt;

enum class Opcode : uint8_t
{
  Const,
  Add,
  Mul,
  Relu,
  Load,
  Store,
  Return
};

// One line of IR.
struct Inst
{
  Opcode op{};
  int id = -1;               // name of the result: v1, v2, ...  (-1 = no result)
  std::vector&lt;int&gt; operands; // names this line reads (e.g. add uses v0 and v2)
  double imm = 0.0;          // only for Const: the number 99 or 1
};

// One basic block: just a vector of Inst, in order.
struct Block
{
  std::string name;
  std::vector&lt;Inst&gt; insts;
};

struct Function
{
  std::string name;
  std::vector&lt;int&gt; args; // v0 is usually the argument, not an Inst
  std::vector&lt;Block&gt; blocks;
  int next_id = 0;
  int fresh()
  {
    return next_id++;
  } // 0, then 1, then 2, ...
};

// ---------------------------------------------------------------------------
// DCE = delete lines whose result nobody needs.
//
// Paper (first test in main). Start at the BOTTOM. live = names still needed.
//
//   return v3          keep (return always stays).  live = {v3}
//   v3 = add v0, v2    v3 is live -&gt; keep.          live = {v3, v0, v2}
//   v2 = const 1       v2 is live -&gt; keep.
//   v1 = const 99      v1 is NOT live -&gt; DELETE.
//
// Flip kept lines back to top-to-bottom:  const 1, add, return.
//
// Walk BACKWARD so you see &quot;who needs this&quot; before you decide to delete.
// Walk forward and you meet const 99 first, with live still empty — wrong.
// store/return are roots: they stay even if they have no id.
// ---------------------------------------------------------------------------
int dce(Function &amp;fn)
{
  int removed = 0;
  for (Block &amp;bb : fn.blocks)
  {
    std::unordered_set&lt;int&gt; live; // names the return still needs
    std::vector&lt;Inst&gt; kept;       // we push bottom-up, reverse at the end
    for (int i = static_cast&lt;int&gt;(bb.insts.size()) - 1; i &gt;= 0; --i)
    {
      const Inst &amp;inst = bb.insts[i];
      const bool root = inst.op == Opcode::Store || inst.op == Opcode::Return;
      const bool result_live = inst.id &gt;= 0 &amp;&amp; live.count(inst.id);
      if (!root &amp;&amp; !result_live)
      {
        ++removed; // nobody needs this result
        continue;
      }
      for (int op : inst.operands)
      {
        live.insert(op); // those names are now needed
      }
      kept.push_back(inst);
    }
    std::reverse(kept.begin(), kept.end());
    bb.insts = std::move(kept);
  }
  return removed;
}

// ---------------------------------------------------------------------------
// CSE (const only) = one &quot;const 2&quot;, not two.
//
// Paper (third test in main):
//   v1 = const 2
//   v2 = const 2          same number -&gt; drop v2, remember v2 means v1
//   v3 = add v0, v1
//   v4 = mul v3, v2       rewrite v2 -&gt; v1 BEFORE you would look at mul
//        return v4
//
// remap: old name -&gt; name we kept.  FIRST rewrite operands, THEN drop duplicate.
// Delete v2 first and mul still says v2 -&gt; broken.
// ---------------------------------------------------------------------------
int cse_const(Function &amp;fn)
{
  int replaced = 0;
  for (Block &amp;bb : fn.blocks)
  {
    std::unordered_map&lt;int, int&gt; remap;          // v2 -&gt; v1
    std::unordered_map&lt;double, int&gt; first_const; // 2.0 -&gt; v1
    std::vector&lt;Inst&gt; kept;
    for (Inst inst : bb.insts)
    {
      for (int &amp;op : inst.operands)
      {
        auto it = remap.find(op);
        if (it != remap.end())
        {
          op = it-&gt;second; // use the first copy&#x27;s id
        }
      }
      if (inst.op == Opcode::Const)
      {
        auto it = first_const.find(inst.imm);
        if (it != first_const.end())
        {
          remap[inst.id] = it-&gt;second;
          ++replaced;
          continue; // do not keep this duplicate const
        }
        first_const.emplace(inst.imm, inst.id);
      }
      kept.push_back(std::move(inst));
    }
    bb.insts = std::move(kept);
  }
  return replaced;
}

int main()
{
  // --- DCE example 1: drop unused const 99 ---
  // v0=x, v1=99, v2=1, v3=add(v0,v2), return v3
  {
    Function fn;
    int x = fn.fresh();
    fn.args.push_back(x);
    Inst dead{Opcode::Const, fn.fresh(), {}, 99.0};
    Inst c1{Opcode::Const, fn.fresh(), {}, 1.0};
    Inst add{Opcode::Add, fn.fresh(), {x, c1.id}};
    Inst ret{Opcode::Return, -1, {add.id}};
    fn.blocks.push_back({&quot;entry&quot;, {dead, c1, add, ret}});
    assert(dce(fn) == 1);                   // only const 99 removed
    assert(fn.blocks[0].insts.size() == 3); // const 1, add, return
    assert(fn.blocks[0].insts[0].imm == 1.0);
  }

  // --- DCE example 2: unused mul, so its const dies too ---
  // v1=const 5, v2=mul(x,v1) unused, v3=relu(x), return v3
  {
    Function fn;
    int x = fn.fresh();
    Inst c{Opcode::Const, fn.fresh(), {}, 5.0};
    Inst mul{Opcode::Mul, fn.fresh(), {x, c.id}};
    Inst relu{Opcode::Relu, fn.fresh(), {x}};
    Inst ret{Opcode::Return, -1, {relu.id}};
    fn.blocks.push_back({&quot;entry&quot;, {c, mul, relu, ret}});
    assert(dce(fn) == 2); // mul and const 5
    assert(fn.blocks[0].insts[0].op == Opcode::Relu);
  }

  // --- CSE: two const 2 -&gt; one; mul must use the first id ---
  {
    Function fn;
    int x = fn.fresh();
    Inst c1{Opcode::Const, fn.fresh(), {}, 2.0};
    Inst c2{Opcode::Const, fn.fresh(), {}, 2.0};
    Inst add{Opcode::Add, fn.fresh(), {x, c1.id}};
    Inst mul{Opcode::Mul, fn.fresh(), {add.id, c2.id}};
    Inst ret{Opcode::Return, -1, {mul.id}};
    fn.blocks.push_back({&quot;entry&quot;, {c1, c2, add, mul, ret}});
    assert(cse_const(fn) == 1);
    assert(fn.blocks[0].insts[2].operands[1] == fn.blocks[0].insts[0].id);
  }

  std::cout &lt;&lt; &quot;STUDY: DCE + CSE ok\n&quot;;
  return 0;
}

<pre>// Real LLVM: load a module, drop trivially dead insts, print IR.
#include &quot;llvm/IR/Function.h&quot;
#include &quot;llvm/IR/InstIterator.h&quot;
#include &quot;llvm/IR/Instructions.h&quot;
#include &quot;llvm/IR/LLVMContext.h&quot;
#include &quot;llvm/IR/Module.h&quot;
#include &quot;llvm/IRReader/IRReader.h&quot;
#include &quot;llvm/Support/SourceMgr.h&quot;
#include &quot;llvm/Support/raw_ostream.h&quot;
#include &quot;llvm/Transforms/Utils/Local.h&quot;

#include &lt;string&gt;

using namespace llvm;

static int dce_function(Function &amp;fn)
{
  int removed = 0;
  bool changed = true;
  while (changed)
  {
    changed = false;
    for (BasicBlock &amp;bb : fn)
    {
      // Backward: a def is only dropped after later uses are gone.
      for (Instruction *inst = &amp;bb.back(); inst != nullptr;)
      {
        Instruction *prev = inst-&gt;getPrevNode();
        if (isInstructionTriviallyDead(inst))
        {
          inst-&gt;eraseFromParent();
          ++removed;
          changed = true;
        }
        inst = prev;
      }
    }
  }
  return removed;
}

int main(int argc, char **argv)
{
  if (argc != 2)
  {
    errs() &lt;&lt; &quot;usage: dce &lt;file.ll&gt;\n&quot;;
    return 1;
  }

  LLVMContext ctx;
  SMDiagnostic err;
  auto mod = parseIRFile(argv[1], err, ctx);
  if (!mod)
  {
    err.print(&quot;dce&quot;, errs());
    return 1;
  }

  int removed = 0;
  for (Function &amp;fn : *mod)
  {
    if (!fn.isDeclaration())
    {
      removed += dce_function(fn);
    }
  }
  errs() &lt;&lt; &quot;removed &quot; &lt;&lt; removed &lt;&lt; &quot;\n&quot;;
  mod-&gt;print(outs(), nullptr);
  return 0;
}

<pre>// Naive GEMM vs 16x16 shared-memory tile.
// Story: same math, fewer global loads of A/B. Print both times.

#include &lt;cuda_runtime.h&gt;
#include &lt;cmath&gt;
#include &lt;cstdio&gt;
#include &lt;cstdlib&gt;
#include &lt;vector&gt;

static constexpr int TILE = 16;

#define CHECK(call)                                                            \
  do                                                                           \
  {                                                                            \
    cudaError_t err = (call);                                                  \
    if (err != cudaSuccess)                                                    \
    {                                                                          \
      fprintf(stderr, &quot;%s:%d %s\n&quot;, __FILE__, __LINE__,                        \
              cudaGetErrorString(err));                                        \
      exit(1);                                                                 \
    }                                                                          \
  } while (0)

__global__ void gemm_naive(const float *A, const float *B, float *C, int N)
{
  int row = blockIdx.y * blockDim.y + threadIdx.y;
  int col = blockIdx.x * blockDim.x + threadIdx.x;
  if (row &gt;= N || col &gt;= N)
  {
    return;
  }
  float acc = 0.f;
  for (int k = 0; k &lt; N; ++k)
  {
    acc += A[row * N + k] * B[k * N + col];
  }
  C[row * N + col] = acc;
}

__global__ void gemm_tiled(const float *A, const float *B, float *C, int N)
{
  __shared__ float As[TILE][TILE];
  __shared__ float Bs[TILE][TILE];
  int row = blockIdx.y * TILE + threadIdx.y;
  int col = blockIdx.x * TILE + threadIdx.x;
  float acc = 0.f;
  for (int t = 0; t &lt; N; t += TILE)
  {
    int a_col = t + threadIdx.x;
    int b_row = t + threadIdx.y;
    As[threadIdx.y][threadIdx.x] =
        (row &lt; N &amp;&amp; a_col &lt; N) ? A[row * N + a_col] : 0.f;
    Bs[threadIdx.y][threadIdx.x] =
        (b_row &lt; N &amp;&amp; col &lt; N) ? B[b_row * N + col] : 0.f;
    __syncthreads();
    for (int k = 0; k &lt; TILE; ++k)
    {
      acc += As[threadIdx.y][k] * Bs[k][threadIdx.x];
    }
    __syncthreads();
  }
  if (row &lt; N &amp;&amp; col &lt; N)
  {
    C[row * N + col] = acc;
  }
}

static float time_ms(void (*launch)(const float *, const float *, float *, int,
                                    int),
                     const float *A, const float *B, float *C, int N, int grid)
{
  launch(A, B, C, N, grid);
  CHECK(cudaDeviceSynchronize());
  cudaEvent_t start, stop;
  CHECK(cudaEventCreate(&amp;start));
  CHECK(cudaEventCreate(&amp;stop));
  CHECK(cudaEventRecord(start));
  for (int i = 0; i &lt; 10; ++i)
  {
    launch(A, B, C, N, grid);
  }
  CHECK(cudaEventRecord(stop));
  CHECK(cudaEventSynchronize(stop));
  float ms = 0.f;
  CHECK(cudaEventElapsedTime(&amp;ms, start, stop));
  CHECK(cudaEventDestroy(start));
  CHECK(cudaEventDestroy(stop));
  return ms / 10.f;
}

static void launch_naive(const float *A, const float *B, float *C, int N, int)
{
  dim3 block(TILE, TILE);
  dim3 grid((N + TILE - 1) / TILE, (N + TILE - 1) / TILE);
  gemm_naive&lt;&lt;&lt;grid, block&gt;&gt;&gt;(A, B, C, N);
}

static void launch_tiled(const float *A, const float *B, float *C, int N, int)
{
  dim3 block(TILE, TILE);
  dim3 grid((N + TILE - 1) / TILE, (N + TILE - 1) / TILE);
  gemm_tiled&lt;&lt;&lt;grid, block&gt;&gt;&gt;(A, B, C, N);
}

int main()
{
  const int N = 1024;
  std::vector&lt;float&gt; hA(N * N), hB(N * N), hC(N * N), hRef(N * N);
  for (int i = 0; i &lt; N * N; ++i)
  {
    hA[i] = 0.001f * (i % 17);
    hB[i] = 0.001f * (i % 13);
  }
  float *A, *B, *C;
  CHECK(cudaMalloc(&amp;A, hA.size() * sizeof(float)));
  CHECK(cudaMalloc(&amp;B, hB.size() * sizeof(float)));
  CHECK(cudaMalloc(&amp;C, hC.size() * sizeof(float)));
  CHECK(cudaMemcpy(A, hA.data(), hA.size() * sizeof(float),
                    cudaMemcpyHostToDevice));
  CHECK(cudaMemcpy(B, hB.data(), hB.size() * sizeof(float),
                    cudaMemcpyHostToDevice));

  launch_naive(A, B, C, N, 0);
  CHECK(cudaDeviceSynchronize());
  CHECK(cudaMemcpy(hRef.data(), C, hRef.size() * sizeof(float),
                    cudaMemcpyDeviceToHost));
  launch_tiled(A, B, C, N, 0);
  CHECK(cudaDeviceSynchronize());
  CHECK(cudaMemcpy(hC.data(), C, hC.size() * sizeof(float),
                    cudaMemcpyDeviceToHost));
  double max_abs = 0;
  for (int i = 0; i &lt; N * N; ++i)
  {
    max_abs = std::max(max_abs, (double)std::fabs(hC[i] - hRef[i]));
  }

  float naive = time_ms(launch_naive, A, B, C, N, 0);
  float tiled = time_ms(launch_tiled, A, B, C, N, 0);
  printf(&quot;N=%d tile=%d\n&quot;, N, TILE);
  printf(&quot;naive  %.3f ms\n&quot;, naive);
  printf(&quot;tiled  %.3f ms\n&quot;, tiled);
  printf(&quot;max |tiled-naive| %.3g\n&quot;, max_abs);
  printf(&quot;why: each A/B element is reused from shared memory inside the tile &quot;
         &quot;instead of reloaded from global memory on every k\n&quot;);

  CHECK(cudaFree(A));
  CHECK(cudaFree(B));
  CHECK(cudaFree(C));
  return max_abs &gt; 1e-3 ? 1 : 0;
}

passes, the same DCE written against the real LLVM C++ API, MLIR fusion and

## Results

**`toy-ir`** — DCE removes a dead `const 99`, and removes two instructions when
a `mul` is unused and its `const` dies with it. CSE collapses duplicate
immediates and rewrites their users.

**`llvm-pass`** — on `input.ll`, `%dead` disappears and the live `add` stays:

```llvm
define i32 @f(i32 %x) {
  %y = add i32 %x, 2
  ret i32 %y
}
```

**`mlir-pass`** — `--linalg-fuse-elementwise-ops` turns two `linalg.generic` ops
into one whose body does `arith.addf` then `arith.mulf`: one loop nest, one
write to the output tensor. `--affine-loop-tile=&amp;quot;tile-size=32&amp;quot;` splits the
`affine.for` over 128 into an outer step-32 loop and an inner 32-trip loop.

**`kernels`** — N=1024, RTX A3000 Laptop, mean of 10 launches:

| Kernel | Time |
|---|---|
| naive | 3.59 ms |
| 16×16 tiled | 2.71 ms |

Max elementwise difference against the naive result is 0.

## Notes

**DCE walks backward.** `store` and `return` are live roots and mark their
operands live. Going forward in a single pass reaches a definition before its
uses, so it would delete values that are still needed. Backward, the live set is
already complete by the time each definition is visited, which also handles
transitively dead chains.

**CSE rewrites operands before deleting.** Operands go through the remap table
first; only then is a duplicate `const` dropped. Delete first and later
instructions still name an id that no longer exists.

**The GEMM win is reuse, not arithmetic.** Both kernels do the same N³
multiply-adds. The naive kernel reloads a row of A and a column of B from global
memory on every `k`. The tiled kernel stages a 16×16 block of each into shared
memory and reuses it across the block, so the bottleneck moves off global
memory bandwidth.

**Ownership.** `unique_ptr` owns each child node; `reset()` frees that subtree,
and no destructor calls `delete` by hand.

&lt;pre&gt;// One file: a list of instructions, then DCE, then CSE.
// Run:  make -C toy-ir study &amp;amp;&amp;amp; ./toy-ir/study
//
// Picture (not a tree): a LIST, top to bottom.
//   v1 = const 99
//   v2 = const 1
//   v3 = add v0, v2
//        return v3
// Names (v0, v1, ...) can be used more than once = a DAG of values.

#include &amp;lt;algorithm&amp;gt;
#include &amp;lt;cassert&amp;gt;
#include &amp;lt;cstdint&amp;gt;
#include &amp;lt;iostream&amp;gt;
#include &amp;lt;string&amp;gt;
#include &amp;lt;unordered_map&amp;gt;
#include &amp;lt;unordered_set&amp;gt;
#include &amp;lt;vector&amp;gt;

enum class Opcode : uint8_t { Const, Add, Mul, Relu, Load, Store, Return };

// One line of IR.
struct Inst {
  Opcode op{};
  int id = -1;               // name of the result: v1, v2, ...  (-1 = no result)
  std::vector&amp;lt;int&amp;gt; operands; // names this line reads (e.g. add uses v0 and v2)
  double imm = 0.0;          // only for Const: the number 99 or 1
};

// One basic block: just a vector of Inst, in order.
struct Block {
  std::string name;
  std::vector&amp;lt;Inst&amp;gt; insts;
};

struct Function {
  std::string name;
  std::vector&amp;lt;int&amp;gt; args; // v0 is usually the argument, not an Inst
  std::vector&amp;lt;Block&amp;gt; blocks;
  int next_id = 0;
  int fresh() { return next_id++; } // 0, then 1, then 2, ...
};

// ---------------------------------------------------------------------------
// DCE = delete lines whose result nobody needs.
//
// Paper (first test in main). Start at the BOTTOM. live = names still needed.
//
//   return v3          keep (return always stays).  live = {v3}
//   v3 = add v0, v2    v3 is live -&amp;gt; keep.          live = {v3, v0, v2}
//   v2 = const 1       v2 is live -&amp;gt; keep.
//   v1 = const 99      v1 is NOT live -&amp;gt; DELETE.
//
// Flip kept lines back to top-to-bottom:  const 1, add, return.
//
// Walk BACKWARD so you see &amp;quot;who needs this&amp;quot; before you decide to delete.
// Walk forward and you meet const 99 first, with live still empty — wrong.
// store/return are roots: they stay even if they have no id.
// ---------------------------------------------------------------------------
int dce(Function &amp;amp;fn) {
  int removed = 0;
  for (Block &amp;amp;bb : fn.blocks) {
    std::unordered_set&amp;lt;int&amp;gt; live; // names the return still needs
    std::vector&amp;lt;Inst&amp;gt; kept;       // we push bottom-up, reverse at the end
    for (int i = static_cast&amp;lt;int&amp;gt;(bb.insts.size()) - 1; i &amp;gt;= 0; --i) {
      const Inst &amp;amp;inst = bb.insts[i];
      const bool root = inst.op == Opcode::Store || inst.op == Opcode::Return;
      const bool result_live = inst.id &amp;gt;= 0 &amp;amp;&amp;amp; live.count(inst.id);
      if (!root &amp;amp;&amp;amp; !result_live) {
        ++removed; // nobody needs this result
        continue;
      }
      for (int op : inst.operands)
        live.insert(op); // those names are now needed
      kept.push_back(inst);
    }
    std::reverse(kept.begin(), kept.end());
    bb.insts = std::move(kept);
  }
  return removed;
}

// ---------------------------------------------------------------------------
// CSE (const only) = one &amp;quot;const 2&amp;quot;, not two.
//
// Paper (third test in main):
//   v1 = const 2
//   v2 = const 2          same number -&amp;gt; drop v2, remember v2 means v1
//   v3 = add v0, v1
//   v4 = mul v3, v2       rewrite v2 -&amp;gt; v1 BEFORE you would look at mul
//        return v4
//
// remap: old name -&amp;gt; name we kept.  FIRST rewrite operands, THEN drop duplicate.
// Delete v2 first and mul still says v2 -&amp;gt; broken.
// ---------------------------------------------------------------------------
int cse_const(Function &amp;amp;fn) {
  int replaced = 0;
  for (Block &amp;amp;bb : fn.blocks) {
    std::unordered_map&amp;lt;int, int&amp;gt; remap;          // v2 -&amp;gt; v1
    std::unordered_map&amp;lt;double, int&amp;gt; first_const; // 2.0 -&amp;gt; v1
    std::vector&amp;lt;Inst&amp;gt; kept;
    for (Inst inst : bb.insts) {
      for (int &amp;amp;op : inst.operands) {
        auto it = remap.find(op);
        if (it != remap.end())
          op = it-&amp;gt;second; // use the first copy&amp;#x27;s id
      }
      if (inst.op == Opcode::Const) {
        auto it = first_const.find(inst.imm);
        if (it != first_const.end()) {
          remap[inst.id] = it-&amp;gt;second;
          ++replaced;
          continue; // do not keep this duplicate const
        }
        first_const.emplace(inst.imm, inst.id);
      }
      kept.push_back(std::move(inst));
    }
    bb.insts = std::move(kept);
  }
  return replaced;
}

int main() {
  // --- DCE example 1: drop unused const 99 ---
  // v0=x, v1=99, v2=1, v3=add(v0,v2), return v3
  {
    Function fn;
    int x = fn.fresh();
    fn.args.push_back(x);
    Inst dead{Opcode::Const, fn.fresh(), {}, 99.0};
    Inst c1{Opcode::Const, fn.fresh(), {}, 1.0};
    Inst add{Opcode::Add, fn.fresh(), {x, c1.id}};
    Inst ret{Opcode::Return, -1, {add.id}};
    fn.blocks.push_back({&amp;quot;entry&amp;quot;, {dead, c1, add, ret}});
    assert(dce(fn) == 1);                      // only const 99 removed
    assert(fn.blocks[0].insts.size() == 3);    // const 1, add, return
    assert(fn.blocks[0].insts[0].imm == 1.0);
  }

  // --- DCE example 2: unused mul, so its const dies too ---
  // v1=const 5, v2=mul(x,v1) unused, v3=relu(x), return v3
  {
    Function fn;
    int x = fn.fresh();
    Inst c{Opcode::Const, fn.fresh(), {}, 5.0};
    Inst mul{Opcode::Mul, fn.fresh(), {x, c.id}};
    Inst relu{Opcode::Relu, fn.fresh(), {x}};
    Inst ret{Opcode::Return, -1, {relu.id}};
    fn.blocks.push_back({&amp;quot;entry&amp;quot;, {c, mul, relu, ret}});
    assert(dce(fn) == 2); // mul and const 5
    assert(fn.blocks[0].insts[0].op == Opcode::Relu);
  }

  // --- CSE: two const 2 -&amp;gt; one; mul must use the first id ---
  {
    Function fn;
    int x = fn.fresh();
    Inst c1{Opcode::Const, fn.fresh(), {}, 2.0};
    Inst c2{Opcode::Const, fn.fresh(), {}, 2.0};
    Inst add{Opcode::Add, fn.fresh(), {x, c1.id}};
    Inst mul{Opcode::Mul, fn.fresh(), {add.id, c2.id}};
    Inst ret{Opcode::Return, -1, {mul.id}};
    fn.blocks.push_back({&amp;quot;entry&amp;quot;, {c1, c2, add, mul, ret}});
    assert(cse_const(fn) == 1);
    assert(fn.blocks[0].insts[2].operands[1] == fn.blocks[0].insts[0].id);
  }

  std::cout &amp;lt;&amp;lt; &amp;quot;STUDY: DCE + CSE ok\n&amp;quot;;
  return 0;
}

&lt;h2 id=&#x27;llvm-pass-dce-cpp&#x27;&gt;llvm-pass/dce.cpp&lt;/h2&gt;
&lt;pre&gt;// Real LLVM: load a module, drop trivially dead insts, print IR.
#include &amp;quot;llvm/IR/Function.h&amp;quot;
#include &amp;quot;llvm/IR/InstIterator.h&amp;quot;
#include &amp;quot;llvm/IR/Instructions.h&amp;quot;
#include &amp;quot;llvm/IR/LLVMContext.h&amp;quot;
#include &amp;quot;llvm/IR/Module.h&amp;quot;
#include &amp;quot;llvm/IRReader/IRReader.h&amp;quot;
#include &amp;quot;llvm/Support/SourceMgr.h&amp;quot;
#include &amp;quot;llvm/Support/raw_ostream.h&amp;quot;
#include &amp;quot;llvm/Transforms/Utils/Local.h&amp;quot;

#include &amp;lt;string&amp;gt;

using namespace llvm;

static int dce_function(Function &amp;amp;fn) {
  int removed = 0;
  bool changed = true;
  while (changed) {
    changed = false;
    for (BasicBlock &amp;amp;bb : fn) {
      // Backward: a def is only dropped after later uses are gone.
      for (Instruction *inst = &amp;amp;bb.back(); inst != nullptr;) {
        Instruction *prev = inst-&amp;gt;getPrevNode();
        if (isInstructionTriviallyDead(inst)) {
          inst-&amp;gt;eraseFromParent();
          ++removed;
          changed = true;
        }
        inst = prev;
      }
    }
  }
  return removed;
}

int main(int argc, char **argv) {
  if (argc != 2) {
    errs() &amp;lt;&amp;lt; &amp;quot;usage: dce &amp;lt;file.ll&amp;gt;\n&amp;quot;;
    return 1;
  }

  LLVMContext ctx;
  SMDiagnostic err;
  auto mod = parseIRFile(argv[1], err, ctx);
  if (!mod) {
    err.print(&amp;quot;dce&amp;quot;, errs());
    return 1;
  }

  int removed = 0;
  for (Function &amp;amp;fn : *mod) {
    if (!fn.isDeclaration())
      removed += dce_function(fn);
  }
  errs() &amp;lt;&amp;lt; &amp;quot;removed &amp;quot; &amp;lt;&amp;lt; removed &amp;lt;&amp;lt; &amp;quot;\n&amp;quot;;
  mod-&amp;gt;print(outs(), nullptr);
  return 0;
}

// After:  mlir-opt --linalg-fuse-elementwise-ops -&amp;gt; one generic: addf then mulf.
#map = affine_map&amp;lt;(d0) -&amp;gt; (d0)&amp;gt;

func.func @add_mul(%a: tensor&amp;lt;8xf32&amp;gt;, %b: tensor&amp;lt;8xf32&amp;gt;, %c: tensor&amp;lt;8xf32&amp;gt;) -&amp;gt; tensor&amp;lt;8xf32&amp;gt; {
  %empty = tensor.empty() : tensor&amp;lt;8xf32&amp;gt;
  %add = linalg.generic {
      indexing_maps = [#map, #map, #map],
      iterator_types = [&amp;quot;parallel&amp;quot;]
    } ins(%a, %b : tensor&amp;lt;8xf32&amp;gt;, tensor&amp;lt;8xf32&amp;gt;)
      outs(%empty : tensor&amp;lt;8xf32&amp;gt;) {
    ^bb0(%x: f32, %y: f32, %out: f32):
      %s = arith.addf %x, %y : f32
      linalg.yield %s : f32
  } -&amp;gt; tensor&amp;lt;8xf32&amp;gt;
  %mul = linalg.generic {
      indexing_maps = [#map, #map, #map],
      iterator_types = [&amp;quot;parallel&amp;quot;]
    } ins(%add, %c : tensor&amp;lt;8xf32&amp;gt;, tensor&amp;lt;8xf32&amp;gt;)

}

&lt;pre&gt;// Naive GEMM vs 16x16 shared-memory tile.
// Story: same math, fewer global loads of A/B. Print both times.

#include &amp;lt;cuda_runtime.h&amp;gt;
#include &amp;lt;cmath&amp;gt;
#include &amp;lt;cstdio&amp;gt;
#include &amp;lt;cstdlib&amp;gt;
#include &amp;lt;vector&amp;gt;

static constexpr int TILE = 16;

#define CHECK(call)                                                            \
  do {                                                                         \
    cudaError_t err = (call);                                                  \
    if (err != cudaSuccess) {                                                  \
      fprintf(stderr, &amp;quot;%s:%d %s\n&amp;quot;, __FILE__, __LINE__,                        \
              cudaGetErrorString(err));                                       \
      exit(1);                                                                 \
    }                                                                          \
  } while (0)

__global__ void gemm_naive(const float *A, const float *B, float *C, int N) {
  int row = blockIdx.y * blockDim.y + threadIdx.y;
  int col = blockIdx.x * blockDim.x + threadIdx.x;
  if (row &amp;gt;= N || col &amp;gt;= N)
    return;
  float acc = 0.f;
  for (int k = 0; k &amp;lt; N; ++k)
    acc += A[row * N + k] * B[k * N + col];
  C[row * N + col] = acc;
}

__global__ void gemm_tiled(const float *A, const float *B, float *C, int N) {
  __shared__ float As[TILE][TILE];
  __shared__ float Bs[TILE][TILE];
  int row = blockIdx.y * TILE + threadIdx.y;
  int col = blockIdx.x * TILE + threadIdx.x;
  float acc = 0.f;
  for (int t = 0; t &amp;lt; N; t += TILE) {
    int a_col = t + threadIdx.x;
    int b_row = t + threadIdx.y;
    As[threadIdx.y][threadIdx.x] =
        (row &amp;lt; N &amp;amp;&amp;amp; a_col &amp;lt; N) ? A[row * N + a_col] : 0.f;
    Bs[threadIdx.y][threadIdx.x] =
        (b_row &amp;lt; N &amp;amp;&amp;amp; col &amp;lt; N) ? B[b_row * N + col] : 0.f;
    __syncthreads();
    for (int k = 0; k &amp;lt; TILE; ++k)
      acc += As[threadIdx.y][k] * Bs[k][threadIdx.x];
    __syncthreads();
  }
  if (row &amp;lt; N &amp;amp;&amp;amp; col &amp;lt; N)
    C[row * N + col] = acc;
}

static float time_ms(void (*launch)(const float *, const float *, float *, int,
                                    int),
                     const float *A, const float *B, float *C, int N, int grid) {
  launch(A, B, C, N, grid);
  CHECK(cudaDeviceSynchronize());
  cudaEvent_t start, stop;
  CHECK(cudaEventCreate(&amp;amp;start));
  CHECK(cudaEventCreate(&amp;amp;stop));
  CHECK(cudaEventRecord(start));
  for (int i = 0; i &amp;lt; 10; ++i)
    launch(A, B, C, N, grid);
  CHECK(cudaEventRecord(stop));
  CHECK(cudaEventSynchronize(stop));
  float ms = 0.f;
  CHECK(cudaEventElapsedTime(&amp;amp;ms, start, stop));
  CHECK(cudaEventDestroy(start));
  CHECK(cudaEventDestroy(stop));
  return ms / 10.f;
}

static void launch_naive(const float *A, const float *B, float *C, int N,
                         int) {
  dim3 block(TILE, TILE);
  dim3 grid((N + TILE - 1) / TILE, (N + TILE - 1) / TILE);
  gemm_naive&amp;lt;&amp;lt;&amp;lt;grid, block&amp;gt;&amp;gt;&amp;gt;(A, B, C, N);
}

static void launch_tiled(const float *A, const float *B, float *C, int N,
                         int) {
  dim3 block(TILE, TILE);
  dim3 grid((N + TILE - 1) / TILE, (N + TILE - 1) / TILE);
  gemm_tiled&amp;lt;&amp;lt;&amp;lt;grid, block&amp;gt;&amp;gt;&amp;gt;(A, B, C, N);
}

int main() {
  const int N = 1024;
  std::vector&amp;lt;float&amp;gt; hA(N * N), hB(N * N), hC(N * N), hRef(N * N);
  for (int i = 0; i &amp;lt; N * N; ++i) {
    hA[i] = 0.001f * (i % 17);
    hB[i] = 0.001f * (i % 13);
  }
  float *A, *B, *C;
  CHECK(cudaMalloc(&amp;amp;A, hA.size() * sizeof(float)));
  CHECK(cudaMalloc(&amp;amp;B, hB.size() * sizeof(float)));
  CHECK(cudaMalloc(&amp;amp;C, hC.size() * sizeof(float)));
  CHECK(cudaMemcpy(A, hA.data(), hA.size() * sizeof(float),
                    cudaMemcpyHostToDevice));
  CHECK(cudaMemcpy(B, hB.data(), hB.size() * sizeof(float),
                    cudaMemcpyHostToDevice));

  launch_naive(A, B, C, N, 0);
  CHECK(cudaDeviceSynchronize());
  CHECK(cudaMemcpy(hRef.data(), C, hRef.size() * sizeof(float),
                    cudaMemcpyDeviceToHost));
  launch_tiled(A, B, C, N, 0);
  CHECK(cudaDeviceSynchronize());
  CHECK(cudaMemcpy(hC.data(), C, hC.size() * sizeof(float),
                    cudaMemcpyDeviceToHost));
  double max_abs = 0;
  for (int i = 0; i &amp;lt; N * N; ++i)
    max_abs = std::max(max_abs, (double)std::fabs(hC[i] - hRef[i]));

  float naive = time_ms(launch_naive, A, B, C, N, 0);
  float tiled = time_ms(launch_tiled, A, B, C, N, 0);
  printf(&amp;quot;N=%d tile=%d\n&amp;quot;, N, TILE);
  printf(&amp;quot;naive  %.3f ms\n&amp;quot;, naive);
  printf(&amp;quot;tiled  %.3f ms\n&amp;quot;, tiled);
  printf(&amp;quot;max |tiled-naive| %.3g\n&amp;quot;, max_abs);
  printf(&amp;quot;why: each A/B element is reused from shared memory inside the tile &amp;quot;
         &amp;quot;instead of reloaded from global memory on every k\n&amp;quot;);

  CHECK(cudaFree(A));
  CHECK(cudaFree(B));
  CHECK(cudaFree(C));
  return max_abs &amp;gt; 1e-3 ? 1 : 0;
}

&amp;lt;pre&amp;gt;# loop

Five small, runnable pieces of a compiler-engineer toolkit: an SSA IR with two
passes, the same DCE written against the real LLVM C++ API, MLIR fusion and
tiling, a C++ memory-ownership set, and a CUDA GEMM with a measured speedup.

Everything here builds and runs. Each directory is one idea, kept small enough
to read in a sitting and rewrite from scratch.

## Layout

| Directory | What it is |
|---|---|
| `toy-ir/` | A tiny SSA IR (`const`, `add`, `mul`, `relu`, `store`, `return`) plus dead-code elimination and constant CSE, in one file |
| `llvm-pass/` | The same DCE on `llvm::Module` / `Instruction`, using `isInstructionTriviallyDead` |
| `mlir-pass/` | `linalg` elementwise fusion and `affine` loop tiling through `mlir-opt` |
| `cpp/` | Eight programs on pointers vs references, `vector` invalidation, `unique_ptr`, and undefined behavior |
| `kernels/` | Naive vs 16×16 shared-memory-tiled GEMM, timed with CUDA events |

## Build and run

```bash
make -C toy-ir study &amp;amp;amp;&amp;amp;amp; ./toy-ir/study
make -C llvm-pass run      # needs llvm-config; override with LLVM_CONFIG=...
make -C mlir-pass run      # needs mlir-opt; override with OPT=...
make -C cpp run
make -C kernels run        # needs nvcc + an NVIDIA GPU
```

## Results

**`toy-ir`** — DCE removes a dead `const 99`, and removes two instructions when
a `mul` is unused and its `const` dies with it. CSE collapses duplicate
immediates and rewrites their users.

**`llvm-pass`** — on `input.ll`, `%dead` disappears and the live `add` stays:

```llvm
define i32 @f(i32 %x) {
  %y = add i32 %x, 2
  ret i32 %y
}
```

**`mlir-pass`** — `--linalg-fuse-elementwise-ops` turns two `linalg.generic` ops
into one whose body does `arith.addf` then `arith.mulf`: one loop nest, one
write to the output tensor. `--affine-loop-tile=&amp;amp;quot;tile-size=32&amp;amp;quot;` splits the
`affine.for` over 128 into an outer step-32 loop and an inner 32-trip loop.

**`kernels`** — N=1024, RTX A3000 Laptop, mean of 10 launches:

| Kernel | Time |
|---|---|
| naive | 3.59 ms |
| 16×16 tiled | 2.71 ms |

Max elementwise difference against the naive result is 0.

## Notes

**DCE walks backward.** `store` and `return` are live roots and mark their
operands live. Going forward in a single pass reaches a definition before its
uses, so it would delete values that are still needed. Backward, the live set is
already complete by the time each definition is visited, which also handles
transitively dead chains.

**CSE rewrites operands before deleting.** Operands go through the remap table
first; only then is a duplicate `const` dropped. Delete first and later
instructions still name an id that no longer exists.

**The GEMM win is reuse, not arithmetic.** Both kernels do the same N³
multiply-adds. The naive kernel reloads a row of A and a column of B from global
memory on every `k`. The tiled kernel stages a 16×16 block of each into shared
memory and reuses it across the block, so the bottleneck moves off global
memory bandwidth.

**Ownership.** `unique_ptr` owns each child node; `reset()` frees that subtree,
and no destructor calls `delete` by hand.

&amp;lt;h2 id=&amp;#x27;toy-ir-STUDY-cpp&amp;#x27;&amp;gt;toy-ir/STUDY.cpp&amp;lt;/h2&amp;gt;
&amp;lt;pre&amp;gt;// One file: a list of instructions, then DCE, then CSE.
// Run:  make -C toy-ir study &amp;amp;amp;&amp;amp;amp; ./toy-ir/study
//
// Picture (not a tree): a LIST, top to bottom.
//   v1 = const 99
//   v2 = const 1
//   v3 = add v0, v2
//        return v3
// Names (v0, v1, ...) can be used more than once = a DAG of values.

#include &amp;amp;lt;algorithm&amp;amp;gt;
#include &amp;amp;lt;cassert&amp;amp;gt;
#include &amp;amp;lt;cstdint&amp;amp;gt;
#include &amp;amp;lt;iostream&amp;amp;gt;
#include &amp;amp;lt;string&amp;amp;gt;
#include &amp;amp;lt;unordered_map&amp;amp;gt;
#include &amp;amp;lt;unordered_set&amp;amp;gt;
#include &amp;amp;lt;vector&amp;amp;gt;

enum class Opcode : uint8_t { Const, Add, Mul, Relu, Load, Store, Return };

// One line of IR.
struct Inst {
  Opcode op{};
  int id = -1;               // name of the result: v1, v2, ...  (-1 = no result)
  std::vector&amp;amp;lt;int&amp;amp;gt; operands; // names this line reads (e.g. add uses v0 and v2)
  double imm = 0.0;          // only for Const: the number 99 or 1
};

// One basic block: just a vector of Inst, in order.
struct Block {
  std::string name;
  std::vector&amp;amp;lt;Inst&amp;amp;gt; insts;
};

struct Function {
  std::string name;
  std::vector&amp;amp;lt;int&amp;amp;gt; args; // v0 is usually the argument, not an Inst
  std::vector&amp;amp;lt;Block&amp;amp;gt; blocks;
  int next_id = 0;
  int fresh() { return next_id++; } // 0, then 1, then 2, ...
};

// ---------------------------------------------------------------------------
// DCE = delete lines whose result nobody needs.
//
// Paper (first test in main). Start at the BOTTOM. live = names still needed.
//
//   return v3          keep (return always stays).  live = {v3}
//   v3 = add v0, v2    v3 is live -&amp;amp;gt; keep.          live = {v3, v0, v2}
//   v2 = const 1       v2 is live -&amp;amp;gt; keep.
//   v1 = const 99      v1 is NOT live -&amp;amp;gt; DELETE.
//
// Flip kept lines back to top-to-bottom:  const 1, add, return.
//
// Walk BACKWARD so you see &amp;amp;quot;who needs this&amp;amp;quot; before you decide to delete.
// Walk forward and you meet const 99 first, with live still empty — wrong.
// store/return are roots: they stay even if they have no id.
// ---------------------------------------------------------------------------
int dce(Function &amp;amp;amp;fn) {
  int removed = 0;
  for (Block &amp;amp;amp;bb : fn.blocks) {
    std::unordered_set&amp;amp;lt;int&amp;amp;gt; live; // names the return still needs
    std::vector&amp;amp;lt;Inst&amp;amp;gt; kept;       // we push bottom-up, reverse at the end
    for (int i = static_cast&amp;amp;lt;int&amp;amp;gt;(bb.insts.size()) - 1; i &amp;amp;gt;= 0; --i) {
      const Inst &amp;amp;amp;inst = bb.insts[i];
      const bool root = inst.op == Opcode::Store || inst.op == Opcode::Return;
      const bool result_live = inst.id &amp;amp;gt;= 0 &amp;amp;amp;&amp;amp;amp; live.count(inst.id);
      if (!root &amp;amp;amp;&amp;amp;amp; !result_live) {
        ++removed; // nobody needs this result
        continue;
      }
      for (int op : inst.operands)
        live.insert(op); // those names are now needed
      kept.push_back(inst);
    }
    std::reverse(kept.begin(), kept.end());
    bb.insts = std::move(kept);
  }
  return removed;
}

// ---------------------------------------------------------------------------
// CSE (const only) = one &amp;amp;quot;const 2&amp;amp;quot;, not two.
//
// Paper (third test in main):
//   v1 = const 2
//   v2 = const 2          same number -&amp;amp;gt; drop v2, remember v2 means v1
//   v3 = add v0, v1
//   v4 = mul v3, v2       rewrite v2 -&amp;amp;gt; v1 BEFORE you would look at mul
//        return v4
//
// remap: old name -&amp;amp;gt; name we kept.  FIRST rewrite operands, THEN drop duplicate.
// Delete v2 first and mul still says v2 -&amp;amp;gt; broken.
// ---------------------------------------------------------------------------
int cse_const(Function &amp;amp;amp;fn) {
  int replaced = 0;
  for (Block &amp;amp;amp;bb : fn.blocks) {
    std::unordered_map&amp;amp;lt;int, int&amp;amp;gt; remap;          // v2 -&amp;amp;gt; v1
    std::unordered_map&amp;amp;lt;double, int&amp;amp;gt; first_const; // 2.0 -&amp;amp;gt; v1
    std::vector&amp;amp;lt;Inst&amp;amp;gt; kept;
    for (Inst inst : bb.insts) {
      for (int &amp;amp;amp;op : inst.operands) {
        auto it = remap.find(op);
        if (it != remap.end())
          op = it-&amp;amp;gt;second; // use the first copy&amp;amp;#x27;s id
      }
      if (inst.op == Opcode::Const) {
        auto it = first_const.find(inst.imm);
        if (it != first_const.end()) {
          remap[inst.id] = it-&amp;amp;gt;second;
          ++replaced;
          continue; // do not keep this duplicate const
        }
        first_const.emplace(inst.imm, inst.id);
      }
      kept.push_back(std::move(inst));
    }
    bb.insts = std::move(kept);
  }
  return replaced;
}

int main() {
  // --- DCE example 1: drop unused const 99 ---
  // v0=x, v1=99, v2=1, v3=add(v0,v2), return v3
  {
    Function fn;
    int x = fn.fresh();
    fn.args.push_back(x);
    Inst dead{Opcode::Const, fn.fresh(), {}, 99.0};
    Inst c1{Opcode::Const, fn.fresh(), {}, 1.0};
    Inst add{Opcode::Add, fn.fresh(), {x, c1.id}};
    Inst ret{Opcode::Return, -1, {add.id}};
    fn.blocks.push_back({&amp;amp;quot;entry&amp;amp;quot;, {dead, c1, add, ret}});
    assert(dce(fn) == 1);                      // only const 99 removed
    assert(fn.blocks[0].insts.size() == 3);    // const 1, add, return
    assert(fn.blocks[0].insts[0].imm == 1.0);
  }

  // --- DCE example 2: unused mul, so its const dies too ---
  // v1=const 5, v2=mul(x,v1) unused, v3=relu(x), return v3
  {
    Function fn;
    int x = fn.fresh();
    Inst c{Opcode::Const, fn.fresh(), {}, 5.0};
    Inst mul{Opcode::Mul, fn.fresh(), {x, c.id}};
    Inst relu{Opcode::Relu, fn.fresh(), {x}};
    Inst ret{Opcode::Return, -1, {relu.id}};
    fn.blocks.push_back({&amp;amp;quot;entry&amp;amp;quot;, {c, mul, relu, ret}});
    assert(dce(fn) == 2); // mul and const 5
    assert(fn.blocks[0].insts[0].op == Opcode::Relu);
  }

  // --- CSE: two const 2 -&amp;amp;gt; one; mul must use the first id ---
  {
    Function fn;
    int x = fn.fresh();
    Inst c1{Opcode::Const, fn.fresh(), {}, 2.0};
    Inst c2{Opcode::Const, fn.fresh(), {}, 2.0};
    Inst add{Opcode::Add, fn.fresh(), {x, c1.id}};
    Inst mul{Opcode::Mul, fn.fresh(), {add.id, c2.id}};
    Inst ret{Opcode::Return, -1, {mul.id}};
    fn.blocks.push_back({&amp;amp;quot;entry&amp;amp;quot;, {c1, c2, add, mul, ret}});
    assert(cse_const(fn) == 1);
    assert(fn.blocks[0].insts[2].operands[1] == fn.blocks[0].insts[0].id);
  }

  std::cout &amp;amp;lt;&amp;amp;lt; &amp;amp;quot;STUDY: DCE + CSE ok\n&amp;amp;quot;;
  return 0;
}

&amp;lt;pre&amp;gt;// Real LLVM: load a module, drop trivially dead insts, print IR.
#include &amp;amp;quot;llvm/IR/Function.h&amp;amp;quot;
#include &amp;amp;quot;llvm/IR/InstIterator.h&amp;amp;quot;
#include &amp;amp;quot;llvm/IR/Instructions.h&amp;amp;quot;
#include &amp;amp;quot;llvm/IR/LLVMContext.h&amp;amp;quot;
#include &amp;amp;quot;llvm/IR/Module.h&amp;amp;quot;
#include &amp;amp;quot;llvm/IRReader/IRReader.h&amp;amp;quot;
#include &amp;amp;quot;llvm/Support/SourceMgr.h&amp;amp;quot;
#include &amp;amp;quot;llvm/Support/raw_ostream.h&amp;amp;quot;
#include &amp;amp;quot;llvm/Transforms/Utils/Local.h&amp;amp;quot;

#include &amp;amp;lt;string&amp;amp;gt;

using namespace llvm;

static int dce_function(Function &amp;amp;amp;fn) {
  int removed = 0;
  bool changed = true;
  while (changed) {
    changed = false;
    for (BasicBlock &amp;amp;amp;bb : fn) {
      // Backward: a def is only dropped after later uses are gone.
      for (Instruction *inst = &amp;amp;amp;bb.back(); inst != nullptr;) {
        Instruction *prev = inst-&amp;amp;gt;getPrevNode();
        if (isInstructionTriviallyDead(inst)) {
          inst-&amp;amp;gt;eraseFromParent();
          ++removed;
          changed = true;
        }
        inst = prev;
      }
    }
  }
  return removed;
}

int main(int argc, char **argv) {
  if (argc != 2) {
    errs() &amp;amp;lt;&amp;amp;lt; &amp;amp;quot;usage: dce &amp;amp;lt;file.ll&amp;amp;gt;\n&amp;amp;quot;;
    return 1;
  }

  LLVMContext ctx;
  SMDiagnostic err;
  auto mod = parseIRFile(argv[1], err, ctx);
  if (!mod) {
    err.print(&amp;amp;quot;dce&amp;amp;quot;, errs());
    return 1;
  }

  int removed = 0;
  for (Function &amp;amp;amp;fn : *mod) {
    if (!fn.isDeclaration())
      removed += dce_function(fn);
  }
  errs() &amp;amp;lt;&amp;amp;lt; &amp;amp;quot;removed &amp;amp;quot; &amp;amp;lt;&amp;amp;lt; removed &amp;amp;lt;&amp;amp;lt; &amp;amp;quot;\n&amp;amp;quot;;
  mod-&amp;amp;gt;print(outs(), nullptr);
  return 0;
}

  %empty = tensor.empty() : tensor&amp;amp;lt;8xf32&amp;amp;gt;
  %add = linalg.generic {
      indexing_maps = [#map, #map, #map],
      iterator_types = [&amp;amp;quot;parallel&amp;amp;quot;]
    } ins(%a, %b : tensor&amp;amp;lt;8xf32&amp;amp;gt;, tensor&amp;amp;lt;8xf32&amp;amp;gt;)

  } -&amp;amp;gt; tensor&amp;amp;lt;8xf32&amp;amp;gt;

&amp;lt;h2 id=&amp;#x27;cpp-01_ptr_ref-cpp&amp;#x27;&amp;gt;cpp/01_ptr_ref.cpp&amp;lt;/h2&amp;gt;
&amp;lt;pre&amp;gt;// 01 — pointer vs reference
#include &amp;amp;lt;iostream&amp;amp;gt;

static void add_ptr(int *p) {
  if (!p)
    return;
  *p += 1;
}

static void add_ref(int &amp;amp;amp;r) { r += 1; }

int main() {
  int x = 10;

&amp;lt;h2 id=&amp;#x27;kernels-gemm-cu&amp;#x27;&amp;gt;kernels/gemm.cu&amp;lt;/h2&amp;gt;
&amp;lt;pre&amp;gt;// Naive GEMM vs 16x16 shared-memory tile.
// Story: same math, fewer global loads of A/B. Print both times.

#include &amp;amp;lt;cuda_runtime.h&amp;amp;gt;
#include &amp;amp;lt;cmath&amp;amp;gt;
#include &amp;amp;lt;cstdio&amp;amp;gt;
#include &amp;amp;lt;cstdlib&amp;amp;gt;
#include &amp;amp;lt;vector&amp;amp;gt;

static constexpr int TILE = 16;

#define CHECK(call)                                                            \
  do {                                                                         \
    cudaError_t err = (call);                                                  \
    if (err != cudaSuccess) {                                                  \
      fprintf(stderr, &amp;amp;quot;%s:%d %s\n&amp;amp;quot;, __FILE__, __LINE__,                        \
              cudaGetErrorString(err));                                       \
      exit(1);                                                                 \
    }                                                                          \
  } while (0)

__global__ void gemm_naive(const float *A, const float *B, float *C, int N) {
  int row = blockIdx.y * blockDim.y + threadIdx.y;
  int col = blockIdx.x * blockDim.x + threadIdx.x;
  if (row &amp;amp;gt;= N || col &amp;amp;gt;= N)
    return;
  float acc = 0.f;
  for (int k = 0; k &amp;amp;lt; N; ++k)
    acc += A[row * N + k] * B[k * N + col];
  C[row * N + col] = acc;
}

__global__ void gemm_tiled(const float *A, const float *B, float *C, int N) {
  __shared__ float As[TILE][TILE];
  __shared__ float Bs[TILE][TILE];
  int row = blockIdx.y * TILE + threadIdx.y;
  int col = blockIdx.x * TILE + threadIdx.x;
  float acc = 0.f;
  for (int t = 0; t &amp;amp;lt; N; t += TILE) {
    int a_col = t + threadIdx.x;
    int b_row = t + threadIdx.y;
    As[threadIdx.y][threadIdx.x] =
        (row &amp;amp;lt; N &amp;amp;amp;&amp;amp;amp; a_col &amp;amp;lt; N) ? A[row * N + a_col] : 0.f;
    Bs[threadIdx.y][threadIdx.x] =
        (b_row &amp;amp;lt; N &amp;amp;amp;&amp;amp;amp; col &amp;amp;lt; N) ? B[b_row * N + col] : 0.f;
    __syncthreads();
    for (int k = 0; k &amp;amp;lt; TILE; ++k)
      acc += As[threadIdx.y][k] * Bs[k][threadIdx.x];
    __syncthreads();
  }
  if (row &amp;amp;lt; N &amp;amp;amp;&amp;amp;amp; col &amp;amp;lt; N)
    C[row * N + col] = acc;
}

static float time_ms(void (*launch)(const float *, const float *, float *, int,
                                    int),
                     const float *A, const float *B, float *C, int N, int grid) {
  launch(A, B, C, N, grid);
  CHECK(cudaDeviceSynchronize());
  cudaEvent_t start, stop;
  CHECK(cudaEventCreate(&amp;amp;amp;start));
  CHECK(cudaEventCreate(&amp;amp;amp;stop));
  CHECK(cudaEventRecord(start));
  for (int i = 0; i &amp;amp;lt; 10; ++i)
    launch(A, B, C, N, grid);
  CHECK(cudaEventRecord(stop));
  CHECK(cudaEventSynchronize(stop));
  float ms = 0.f;
  CHECK(cudaEventElapsedTime(&amp;amp;amp;ms, start, stop));
  CHECK(cudaEventDestroy(start));
  CHECK(cudaEventDestroy(stop));
  return ms / 10.f;
}

static void launch_naive(const float *A, const float *B, float *C, int N,
                         int) {
  dim3 block(TILE, TILE);
  dim3 grid((N + TILE - 1) / TILE, (N + TILE - 1) / TILE);
  gemm_naive&amp;amp;lt;&amp;amp;lt;&amp;amp;lt;grid, block&amp;amp;gt;&amp;amp;gt;&amp;amp;gt;(A, B, C, N);
}

static void launch_tiled(const float *A, const float *B, float *C, int N,
                         int) {
  dim3 block(TILE, TILE);
  dim3 grid((N + TILE - 1) / TILE, (N + TILE - 1) / TILE);
  gemm_tiled&amp;amp;lt;&amp;amp;lt;&amp;amp;lt;grid, block&amp;amp;gt;&amp;amp;gt;&amp;amp;gt;(A, B, C, N);
}

int main() {
  const int N = 1024;
  std::vector&amp;amp;lt;float&amp;amp;gt; hA(N * N), hB(N * N), hC(N * N), hRef(N * N);
  for (int i = 0; i &amp;amp;lt; N * N; ++i) {
    hA[i] = 0.001f * (i % 17);
    hB[i] = 0.001f * (i % 13);
  }
  float *A, *B, *C;
  CHECK(cudaMalloc(&amp;amp;amp;A, hA.size() * sizeof(float)));
  CHECK(cudaMalloc(&amp;amp;amp;B, hB.size() * sizeof(float)));
  CHECK(cudaMalloc(&amp;amp;amp;C, hC.size() * sizeof(float)));
  CHECK(cudaMemcpy(A, hA.data(), hA.size() * sizeof(float),
                    cudaMemcpyHostToDevice));
  CHECK(cudaMemcpy(B, hB.data(), hB.size() * sizeof(float),
                    cudaMemcpyHostToDevice));

  launch_naive(A, B, C, N, 0);
  CHECK(cudaDeviceSynchronize());
  CHECK(cudaMemcpy(hRef.data(), C, hRef.size() * sizeof(float),
                    cudaMemcpyDeviceToHost));
  launch_tiled(A, B, C, N, 0);
  CHECK(cudaDeviceSynchronize());
  CHECK(cudaMemcpy(hC.data(), C, hC.size() * sizeof(float),
                    cudaMemcpyDeviceToHost));
  double max_abs = 0;
  for (int i = 0; i &amp;amp;lt; N * N; ++i)
    max_abs = std::max(max_abs, (double)std::fabs(hC[i] - hRef[i]));

  float naive = time_ms(launch_naive, A, B, C, N, 0);
  float tiled = time_ms(launch_tiled, A, B, C, N, 0);
  printf(&amp;amp;quot;N=%d tile=%d\n&amp;amp;quot;, N, TILE);
  printf(&amp;amp;quot;naive  %.3f ms\n&amp;amp;quot;, naive);
  printf(&amp;amp;quot;tiled  %.3f ms\n&amp;amp;quot;, tiled);
  printf(&amp;amp;quot;max |tiled-naive| %.3g\n&amp;amp;quot;, max_abs);
  printf(&amp;amp;quot;why: each A/B element is reused from shared memory inside the tile &amp;amp;quot;
         &amp;amp;quot;instead of reloaded from global memory on every k\n&amp;amp;quot;);

  CHECK(cudaFree(A));
  CHECK(cudaFree(B));
  CHECK(cudaFree(C));
  return max_abs &amp;amp;gt; 1e-3 ? 1 : 0;
}
